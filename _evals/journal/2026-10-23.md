## Why it went this way

- The skill's value on these cases is not judgement in the prose; it is the script plus one
  piece of knowledge the agent cannot see in the report: which fields the script did not check.
  Removing the explanation of the script's comparison rule removed that knowledge.
- Imperative lookup wording ("look each one up") is read as an invitation to web search, and web
  searches are the only cost lever (cost model of 10-12). Naming the scripted route, with the
  exact query shape, kept the follow-up and dropped the cost below the full skill's.
