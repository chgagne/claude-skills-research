# Style defaults

Neutral conventions of ML conference prose, used when no field profile exists and as the
floor under every profile. Keys are what `rule` fields cite as `defaults:<key>`.

| Key | Rule |
|---|---|
| `agreement` | Subject and verb agree; watch `data`, `location`, `number of X`. |
| `articles` | Countable singular nouns take an article; defined terms take `the` after first use. |
| `tense` | Present for what the paper does and shows; past for what was run; present perfect for prior work only when the time matters. |
| `one-claim` | One claim per sentence; split at `, and` joining two independent results. |
| `subject-verb-near` | Keep subject and verb within about eight words. |
| `active-agent` | Use the active voice when the agent is the point (`we train`, `the block writes`). Passive is fine when the agent is obvious or irrelevant. |
| `no-filler` | Delete `in order to`, `it is worth noting that`, `it should be noted`, `the fact that`, `note that` at sentence start. |
| `number-not-intensifier` | Replace `very`, `substantially`, `dramatically`, `significantly` (non-statistical) with the number when a table has it; otherwise delete. |
| `hedge-once` | One hedge per claim. `may possibly suggest` → `may suggest`. Never remove a hedge from a limitation. |
| `define-before-use` | A coined term is defined in the sentence where it first appears, in italics, and used unchanged thereafter. |
| `one-name` | One name per concept across the paper; the glossary decides which. |
| `figure-first-mention` | A figure or table is introduced in prose before its content is discussed. |
| `claim-then-evidence` | State the finding, then the numbers that support it, then the caveat. |
| `topic-sentence` | The first sentence of a paragraph says what the paragraph establishes. |
| `cite-spacing` | `text~\citep{}` or `text \citep{}`; never `text.\citep{}`; multi-reference lists in one `\citep`. |
| `ref-form` | Follow the paper's dominant form (`Figure~\ref` or `\fref`), never mix. |
| `numbers` | Numbers under ten in words unless they are measurements; units with `\,`; percentages as `40\%`; ranges with `--`. |
| `abbreviations` | Spell out at first use with the abbreviation in parentheses; do not abbreviate a term used fewer than three times. |
| `register` | No `kind of`, `a lot`, `huge`, `pretty`, `basically`, `interestingly`, `surprisingly`. |
| `metaphor` | A metaphor is acceptable once, when defined; not as the working verb for a technical event. |
| `parallel` | Items in a list or contribution enumeration share grammatical form. |
| `contributions-match` | Each contribution bullet maps to a section that demonstrates it. |
